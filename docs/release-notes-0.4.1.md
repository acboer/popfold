## Popfold 0.4.1

### Improved
- The installer and the app now carry publisher details (publisher, description, copyright and project links). You can see them in the file's *Properties › Details* and in *Settings › Apps*, which helps Windows and antivirus software recognize Popfold.

No other changes since 0.4.0.

### Install
Download **Popfold-Setup-0.4.1.exe** below and run it. Installing over an older version keeps your folders. Requires Windows 10 (1809) or 11, 64-bit.

Popfold isn't digitally signed yet, so Windows may say *"Windows protected your PC"*: click **More info** → **Run anyway**.

---
